# What This Is

This directory is a snapshot clone of **woodmanlegion/claw-gh-install** from GitHub:

- **Source:** https://github.com/woodmanlegion/claw-gh-install
- **Author:** https://github.com/woodmanlegion

`claw-gh-install` is a skill that lets OpenClaw install plugins and skills directly from GitHub repos without npm publishing. The actual installed skill lives at `~/.openclaw/workspace/skills/claw-gh-install/`, and the binary is symlinked at `~/.openclaw/workspace/bin/claw-gh-install`.

This temp clone was used for the bootstrap install. Future updates are self-managed via `claw-gh-install --update claw-gh-install`.
